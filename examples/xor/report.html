03 / HOW LEARNING HAPPENS

The chain rule supplies the direction.

Z1 = X @ W1 + b1       H = tanh(Z1)
Z2 = H @ W2 + b2       P = sigmoid(Z2)
L  = mean(logaddexp(0, where(Y == 1, -Z2, Z2)))

dZ2 = where(Y == 1, -sigmoid(-Z2), sigmoid(Z2)) / N
dW2 = H.T @ dZ2        db2 = sum(dZ2, axis=0)
E   = exp(-abs(Z1))
dZ1 = (dZ2 @ W2.T) * (2 * E / (1 + E * E))**2
dW1 = X.T @ dZ1        db1 = sum(dZ1, axis=0)

parameter = parameter - learning_rate * gradient

N is the number of examples, four here. In exact arithmetic the loss equals mean(logaddexp(0, Z2) - Y * Z2), dZ2 equals (P - Y) / N, and (2 * E / (1 + E * E))**2 equals 1 - H**2. The code evaluates these forms from Z2 and Z1, so a P that rounds to exactly 1 or an H that rounds to ±1 cannot turn a tiny loss or derivative into 0. A positive derivative means increasing that parameter locally increases the loss; subtracting the gradient takes a small step in the opposite direction. The learning rate determines the step size.

Read docs/mathematics.md in the repository for the full derivation, a worked numerical example, and the reason one linear classifier cannot solve XOR. Then try docs/exercises.md.
