Work through one threshold

Suppose targets are [0, 1, 0, 1] and outputs are [0.1, 0.4, 0.4, 0.9]. At τ = 0.5: TP = 1, FP = 0, FN = 1, TN = 2. If a missed positive costs 3 and a false alarm costs 1, mean cost is (0 + 3) / 4 = 0.75.

At τ = 0.4, both tied 0.4 scores enter class 1: TP = 2, FP = 1, FN = 0, TN = 1. Mean cost falls to 1 / 4 = 0.25. Moving a threshold changes decisions; probabilities and weights stay fixed.

There are four positive–negative score pairs: three wins and one tie, so ROC AUC = (3 + ½) / 4 = 7/8. Recall rises by ½ at precision 1, then by ½ at precision 2/3, giving AP = ½ + ⅓ = 5/6.

Brier = (0.1² + 0.6² + 0.4² + 0.1²) / 4 = 0.135. With two bins [0, 0.5) and [0.5, 1], ECE = (3/4) × |0.3 − 1/3| + (1/4) × |0.9 − 1| = 0.05. The recorded report uses ten bins; ECE changes with the binning choice.

Why use validation for the threshold?

The threshold is another selected setting. Choosing it to minimize test mistakes uses the test labels for model selection. This report chooses among the validation scores, 0.5 and an all-negative rule. Ties prefer the threshold closest to 0.5, then the higher threshold.

How to read calibration

In a bin with mean output 0.7 and an observed positive fraction of 0.5, the absolute calibration gap is 0.2. ECE averages these gaps weighted by bin count. Brier is the mean of (p − y)². Neither measure makes a small synthetic test into a guarantee about future data.

Follow the derivative through the network

Standardize each raw input using the saved training mean and scale. For B training rows, the output derivative is dZ₂ = (P − Y) / B. Then dW₂ = HᵀdZ₂ + λW₂, dZ₁ = (dZ₂W₂ᵀ) ⊙ (1 − H²), and dW₁ = X̃ᵀdZ₁ + λW₁. Bias derivatives sum over rows and have no L2 penalty.

The objective is mean BCE plus ½λ(‖W₁‖² + ‖W₂‖²). Computing BCE from logits avoids taking log(0) when sigmoid rounds to 0 or 1.

Why can a descent step increase loss?

The tangent predicts ΔJ ≈ −ηg² for one parameter, or −η‖∇J‖² for all parameters. This prediction is local. Curvature matters for a finite step, so a large learning rate can overshoot.

The chart varies only the selected coordinate; an all-parameter step follows another direction. Neither a flat slice nor a small gradient proves a global minimum. Compare the predicted and actual changes, then use Undo to try a smaller η.

Work one update by hand

Take one standardized input [0, 0] with target 1, one hidden neuron, W₁ = [1, −1]ᵀ, b₁ = 0, W₂ = 2, b₂ = 0 and λ = 0.1. Then h = 0, p = 0.5, BCE = log(2), penalty = 0.3 and J ≈ 0.993147.

For b₂, the derivative is p − y = −0.5. A coordinate step with η = 0.2 makes b₂ = 0.1. The predicted change is −0.05. The actual objective becomes log(1 + exp(−0.1)) + 0.3 ≈ 0.944397: a change of −0.048751.

06 / CONNECT CODE TO MATHEMATICS

The whole model, in four lines.

01X̃ = (X − μtrain) / σtrain

02H = tanh(X̃W₁ + b₁)

03P = sigmoid(HW₂ + b₂)

04J = mean BCE + ½λ(‖W₁‖² + ‖W₂‖²)

What makes this a learning experiment?

Mini-batches estimate a gradient from a subset of training rows. Adam tracks first and second gradient moments and corrects their initial bias. L2 penalizes large weights. Early stopping chooses when to stop using validation behavior.

Python training uses explicit NumPy derivatives and optimizer updates. The gradient sandbox mirrors the network calculations in JavaScript. Neither uses an automatic differentiation framework.

Why divide by the batch size?

The data loss is a mean. Its derivative begins with dZ₂ = (P − Y) / B, where B is the current batch size. The last, shorter batch uses its own size. The L2 derivative is λW; biases receive no L2 penalty.

Why not fit the scaler on every point?

Using validation or test values to calculate the mean and standard deviation lets evaluation data influence training. This lab fits μ and σ on training inputs only, then applies those same numbers everywhere.

Why compare with a linear model?

A network can fit curved boundaries, but a more complex model is not automatically better. The baseline makes the added hidden layer's effect measurable for this experiment.
